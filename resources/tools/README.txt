ضع هنا أدوات Android Platform-Tools (من موقع Google الرسمي):

  adb.exe
  fastboot.exe
  AdbWinApi.dll
  AdbWinUsbApi.dll

الرابط الرسمي للتحميل:
  https://developer.android.com/tools/releases/platform-tools

بعد وضع الملفات هنا يجدها CAPji teel تلقائياً (بدون تثبيت ADB في النظام).
ويمكنك بدلاً من ذلك تحديد مسار adb.exe يدوياً من: الإعدادات داخل البرنامج.

ملاحظة: عند بناء نسخة التثبيت (npm run dist) يُنسخ هذا المجلد داخل البرنامج تلقائياً.
